# Inview URL Finder

Automated URL discovery tool for [inview.nl](https://www.inview.nl) — searches for legal commentary documents by title and saves the resolved URLs to an Excel file. Includes a live browser dashboard for monitoring progress.

---

## Features

- 🔍 Searches inview.nl for each title in your Excel file
- ⏳ Waits for ID-based URLs to resolve to readable slugs before matching
- 🔁 Retry logic — attempts each title up to 2 times before marking as not found
- 💾 Crash-safe — saves progress after every single row
- ▶️ Resume support — re-running continues from where it left off
- 📊 Live dashboard — real-time progress bar, found/not-found tables with search
- 🖥️ Rich terminal progress bar with ETA

---

## Requirements

- Python **3.10+**
- Google Chrome installed
- ChromeDriver matching your Chrome version ([download](https://chromedriver.chromium.org/downloads) or use `chromedriver-autoinstaller`)
- An inview.nl account (login is done manually in the browser)

## Setup & Usage

### 1. Clone the repo

```bash
git clone https://github.com/your-username/inview-url-finder.git
cd inview-url-finder
```

### 2. Add your input file

Place your Excel file in the project folder and name it:

```
T_C.xlsx
```

The script reads titles from **column B** (the second column, index 1).

### 3. Run

```bash
python setup.py
```

This will:
1. Install all required Python packages automatically
2. Write `inview_url_finder.py` and `dashboard.html` to the current folder
3. Start a local HTTP server for the dashboard
4. Open the dashboard in your browser at `http://localhost:8000/dashboard.html`
5. Launch Chrome and prompt you to log in manually

### 4. Log in to inview.nl

When Chrome opens, log in to your inview.nl account. Once logged in, return to the terminal and press **Enter** to begin scraping.

## Dashboard

The dashboard auto-updates every 2 seconds and shows:

- **Total / Found / Not Found / Pending** counts with percentages
- **Progress bar** across all rows
- **Currently processing** — the title being searched right now
- **Found tab** — searchable table of all matched rows with clickable URLs
- **Not Found tab** — searchable table of all failed rows for review

> The dashboard is served over a local HTTP server (not `file://`) so `fetch()` works correctly in all browsers.

## Configuration

Edit the constants at the top of `inview_url_finder.py` (or inside `setup.py` before the `SCRAPER_PY` string) to adjust behaviour:

| Constant | Default | Description |
|---|---|---|
| `INPUT_FILE` | `T_C.xlsx` | Input Excel filename |
| `OUTPUT_FILE` | `output_TC.xlsx` | Output Excel filename |
| `MAX_RETRIES` | `2` | Search attempts per title |
| `SEARCH_WAIT` | `3` | Seconds to wait after searching |
| `REDIRECT_WAIT` | `3` | Seconds to wait after navigating to a link |
| `SLUG_WAIT_TIMEOUT` | `10.0` | Max seconds to wait for ID→slug redirect |
| `DASHBOARD_PORT` | `8000` | Local port for the dashboard server |

## Resuming After a Crash

Just re-run:

```bash
python setup.py
```

The script detects `output_TC.xlsx` and skips all rows that already have a URL. Only pending and `not found` rows are retried.

---

## Stopping

Press `Ctrl+C` in the terminal. Progress is saved up to the last completed row.

## Troubleshooting

**Chrome doesn't open / ChromeDriver error**
Make sure ChromeDriver is installed and matches your Chrome version. The easiest fix:
```bash
pip install chromedriver-autoinstaller
```
Then add to the top of `inview_url_finder.py`:
```python
import chromedriver_autoinstaller
chromedriver_autoinstaller.install()
```

**Dashboard shows "waiting for scraper to start…"**
The dashboard polls `progress.json` — this file is created as soon as the scraper starts. If it never appears, make sure `setup.py` is running without errors in the terminal.

**Dashboard not updating / blank**
Make sure you're accessing the dashboard via `http://localhost:8000/dashboard.html` and **not** by opening the HTML file directly (`file://`). The `file://` protocol blocks the `fetch()` calls that load `progress.json`.

**Matches are being missed**
- Increase `SLUG_WAIT_TIMEOUT` if the site is slow to redirect
- Increase `SEARCH_WAIT` if results aren't loading in time
- Check the terminal logs — each slug/ID check is printed with ✅ / ⚠️
